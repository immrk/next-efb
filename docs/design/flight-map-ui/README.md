# NextEFB 航空地图 UI 视觉提案

这组设计图用于统一地图航路点、航点信息层和航路线的视觉语言。PNG 是视觉方向稿；正式实现时应使用 SVG、Leaflet `DivIcon`、Canvas 或 CSS 绘制，以保证缩放清晰和交互状态可控。

## 设计图

1. `01-waypoint-symbol-system.png`：航路点符号、尺寸和状态系统。
2. `02-waypoint-information-components.png`：常驻标签、悬停提示、选中卡片、航段信息、限制条件和触控底部卡片。
3. `03-flight-planning-map-concept.png`：完整桌面地图与航路规划界面。

## 航路线分层

建议按以下顺序自下而上绘制：

1. 航路暗色衬线：`7–9 px`，`#071019`，用于复杂底图上的稳定对比度。
2. 计划航路：`3 px`，`#C975FF`。
3. 已飞航段：沿用计划航路色，透明度降至 `35–45%`。
4. 当前航段：`3–4 px`，`#39D4FF`，添加低密度方向箭头。
5. SID/STAR：分别使用离场绿和到场红；程序尚未确认时降低透明度。
6. 雷达引导/不连续航段：短虚线配空心箭头，避免误解为已确定直飞。
7. 航段信息：在足够长的航段中点显示航向、距离和 ETE；低缩放级别自动隐藏。

## 航点符号原则

- 类型主要靠轮廓区分，颜色只表达状态，避免把所有点画成不同颜色的圆点。
- 默认、航路内、选中三种状态分别使用中性色、航路紫、青色选择环。
- 常用地图尺寸为 `16 / 20 / 24 px`；触控命中区域至少 `36 px`。
- 标签使用深色描边或半透明底板，标识符优先，附加信息按缩放级别渐进显示。
- 起点、终点、备降场、用户点必须同时具有独立形状和语义色。

## 信息层级

- 常驻层：符号 + 标识符。
- 悬停层：类型、坐标、频率或高度。
- 选中层：完整信息、下一航点、距离、限制条件和主要操作。
- 触控设备：使用底部卡片承载完整信息，避免小浮窗遮挡手指和航线。
- 高度与速度限制使用琥珀色独立胶囊，不与标识符混成一行。
